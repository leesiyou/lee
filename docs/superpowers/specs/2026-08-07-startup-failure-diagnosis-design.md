# 创业失败诊断 H5 发布设计

## 目标

将用户提供的 `startup-failure-diagnosis` H5 作为 2026-08-07 日更内容发布到 Myhood Daily，并生成一张可直接放入微信公众号正文的 9:16 引导海报。

## 内容边界

- 保留文章现有核心论证：经验并非免疫，成功案例只有在关键条件相同且因果机制成立时才可能迁移。
- 海报使用独立的新主视觉，不沿用“拿钱续命”输液袋画面。
- 海报标题固定为“为什么照着成功案例复制，公司还是会倒闭？”，行动文案固定为“点击原文看”。
- 不把行业估算、相关性或个案包装成确定因果；现有精确数据必须保留来源入口。

## 视觉方案

采用“成功案例复印件 → 同质化公司骨牌 → 连锁倒塌”的纵向概念图。整体为深黑、冷银和风险红，中央使用复印件、商业蓝图和坍塌的办公楼形成由上至下的因果动线；标题位于上半部安全区，“点击原文看”位于底部安全区。输出比例严格为 9:16，避免二维码、品牌 Logo、英文水印和无关小字。

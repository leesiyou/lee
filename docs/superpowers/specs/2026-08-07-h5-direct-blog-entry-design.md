# H5 直接进入博客设计

## 目标

把已发布的今日 H5 作为正式博客文章显示在首页。访客点击文章卡片的封面、标题或“继续阅读”后，直接进入对应 H5，不经过普通文章正文页。

## 方案

- 在 Directus `articles` 中增加可选字段 `h5_path`，只接受站内 `/h5/` 路径。
- 普通文章未填写该字段时，继续使用 `/posts/<slug>`，行为不变。
- 首页文章卡片通过统一链接函数选择 `h5_path` 或普通文章地址。
- 如果用户从 RSS、搜索结果或旧链接进入 `/posts/<slug>`，文章路由读取到 `h5_path` 后执行站内重定向，最终仍进入 H5。
- 今日文章写入 Directus，状态为 `published`，分类为“创业与商业”，作者为“李思友”，并使用现有公众号海报作为封面。

- 标题：为什么照着成功案例复制，公司还是会倒闭？
- slug：`startup-failure-diagnosis`

## 安全和兼容

- `h5_path` 必须是以 `/h5/` 开头的站内绝对路径，禁止协议、域名、`//` 和路径穿越。
- Directus 中没有 `h5_path` 的既有文章不受影响。
- 文章封面上传到 Directus 文件库，不使用本机路径。

- 首页卡片链接直接指向 H5。
- `/posts/startup-failure-diagnosis` 返回站内重定向并到达 H5。
- H5、公网首页和封面资源均返回 HTTP 200。

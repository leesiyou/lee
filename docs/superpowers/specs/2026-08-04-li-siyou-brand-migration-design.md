# 李思友的思想实验室品牌迁移设计

## 目标

把博客的站点品牌和作者身份统一为“李思友的思想实验室”与“李思友”。迁移完成后，公网页面、生成内容、当前代码、配置、测试和有效文档不再出现旧品牌或旧作者称呼。

## 变更范围

- 前台导航、标题、页脚、无障碍标签与默认页面标题。
- SEO、Open Graph、RSS、favicon 说明与现有品牌封面文字。
- Directus 默认站点设置、默认作者及生产库中的现有站点和作者数据。
- README、运行脚本、测试断言和当前有效文档。
- 本地项目目录名称与依赖该绝对路径的脚本。

## 不变范围

- 公网域名和现有文章 URL 保持不变，避免公众号历史链接失效。
- 数据库结构、文章 slug、分类、图片和容器拓扑保持不变。
- Git 历史提交不做破坏性重写；验收只针对当前工作树和当前部署产物。
- 用户已有的未跟踪文件保持原样，不纳入此次提交。

## 实施方式

先集中定义站点品牌常量并替换所有运行时硬编码，再更新 Directus 初始化数据和既有内容，随后修正资源与文档。最后部署新镜像并核验公网首页、文章页、RSS、页面源代码和当前仓库全文搜索。

## 验收标准

- 公网首页显示“李思友的思想实验室”。
- 文章页作者显示“李思友”。
- 页面标题、SEO、Open Graph、RSS 与页脚使用新品牌。
- 当前仓库受版本控制文件全文搜索不到旧品牌和旧作者称呼。
- 定向测试、类型检查、构建和公网 HTTP 检查通过。
- 不改变现有公网 URL，不破坏未跟踪文件。

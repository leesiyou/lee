# 微信公众号优先与节点小宝单入口设计

日期：2026-08-01

## 目标与边界

第一阶段不使用独立域名、公共 DNS、独立证书或微信 JS-SDK。节点小宝只公开 Astro H5 博客前台，微信公众号通过固定菜单、阅读原文、公众号素材和分享海报为博客导流。Directus 只允许飞牛局域网访问，不创建公共后台映射。

保留后续微信公众号草稿 API，但未配置 AppID、AppSecret 和接口权限时不构成上线阻塞，不自动群发，也不声称已经写入公众号草稿箱。

## 访问架构

```text
微信公众号菜单或阅读原文
  -> 节点小宝提供的真实 HTTPS 地址
  -> 飞牛 127.0.0.1:18432
  -> Caddy :8080
  -> Astro SSR :4321
  -> Directus :8055
  -> PostgreSQL / Redis

飞牛局域网
  -> http://192.168.5.104:18055
  -> Caddy :8081
  -> Directus :8055
```

宿主机只映射博客 `18432` 和局域网后台 `18055`。节点小宝只新增 `18432` 的一个 HTTPS 前台映射。PostgreSQL、Redis、Docker API、SSH、飞牛后台和 Directus `18055` 均不进入节点小宝公网规则。

## 可配置 URL

- `PUBLIC_BASE_URL`：博客对外基址。获得节点小宝 HTTPS 地址前使用 LAN 验收地址，获得后只修改该变量并重建 web。
- `PUBLIC_ADMIN_URL`：Directus 后台入口，第一阶段固定为飞牛局域网 `http://192.168.5.104:18055`。
- `DIRECTUS_PUBLIC_URL`：Directus 自身生成文件地址和回调地址，第一阶段与局域网后台地址一致。

文章链接、canonical、Open Graph、RSS、sitemap、分享链接、阅读原文、素材页和二维码都从 `PUBLIC_BASE_URL` 生成，代码不保存节点小宝具体地址。

## 前台图片同源代理

公开页面不得把 `DIRECTUS_PUBLIC_URL` 或 `192.168.5.104` 写入 HTML。Caddy 前台入口增加 `/assets/*` 到 Directus 的同源代理，公开文章封面统一生成：

```text
<PUBLIC_BASE_URL>/assets/<file-id>
```

这样节点小宝 HTTPS 页面中的图片仍使用同一个公网 HTTPS 主机，不暴露局域网后台地址，也不产生 HTTPS 页面加载 HTTP 图片的问题。Directus 管理后台继续使用自身 LAN 地址。

## 公众号素材页

每篇已发布且发布时间已到的文章自动拥有：

```text
<PUBLIC_BASE_URL>/wechat/material/<slug>
```

素材页允许拿到链接的人访问，但不出现在首页、RSS、sitemap 或站内导航，并返回 `noindex`/`no-store`，防止被搜索引擎收录或中间缓存。草稿、未来排期和归档文章返回 404。

素材页移动端展示并支持复制：

- 公众号标题
- 公众号摘要
- 同源封面预览和下载
- 从 `wechat_content` 或正文提取的 3—5 段精华
- 第一条引用金句；没有引用时使用摘要
- 完整 H5/阅读原文地址
- 朋友圈分享文案
- 文章二维码及二维码图片下载

复制功能优先使用 Clipboard API，失败时回退为选中文本和明确提示。页面不调用微信 JS-SDK，不声称具备自定义微信分享能力。

## Directus 操作

文章详情页操作统一命名为“生成公众号素材”。操作先读取当前文章并确认已经发布，再返回素材页地址和以下中性消息：

```text
当前已生成公众号发布素材。自动写入公众号草稿箱功能尚未配置，不影响博客发布。
```

当且仅当 `WECHAT_DRAFT_ENABLED=true` 且 AppID/AppSecret 完整时，同一操作在生成素材后尝试写入公众号草稿箱，结果仍进入 Directus 通知，最终发表必须由用户在公众号后台人工审核。

## 日更数据流

用户每天只在 Directus 新建文章、填写标题正文、上传封面、选择模板并发布。发布后 Astro SSR 立即读取 Directus，首页、独立 H5、分类、归档、RSS、sitemap、公众号素材、阅读原文、朋友圈文案和二维码均按请求实时生成，不需要重新构建或部署。

公众号菜单只需设置一次，指向 `PUBLIC_BASE_URL`。博客发布不会自动产生公众号动态或自动群发；用户从素材页复制内容到公众号后台，审核后手动发表。

## 失败处理

- 未获得节点小宝地址：LAN 功能可验收，报告保持公网和微信测试未完成，不伪造地址。
- 文章未发布：素材页和生成操作返回明确的 404/未发布提示。
- 无封面：文字素材和二维码仍生成，封面区域提示先上传封面；开启官方草稿 API 时仍拒绝创建无封面草稿。
- Clipboard API 不可用：保留可选中文本与手工复制提示。
- 微信凭据缺失：返回 `material_ready`，HTTP 成功，不把“未配置草稿 API”当作博客失败。
- Directus 不可用：素材页显示友好 503，不泄露堆栈、Token 或内部地址。

## 迁移与回滚

变更前创建当前数据库和配置备份。Compose 将 Caddy 宿主机端口从 `19080/19081` 改为 `18432/18055`，不改变容器内部端口、数据库目录或上传目录。先更新代码和 NAS `.env`，再只重建 Caddy、web 和需要刷新 URL 的 Directus；PostgreSQL/Redis 不迁移。

回滚时恢复备份的 Compose、`.env` 中 URL 和上一不可变 web 镜像 tag，重新创建 Caddy/web/Directus。节点小宝若已新增博客规则，只删除本次新增规则，不触碰旧映射。

## 验收

自动测试覆盖 URL 派生、同源图片、素材字段、noindex/no-store、草稿门禁、按钮文案、端口、Caddy 代理和未配置微信凭据的中性成功结果。

NAS 验收覆盖五容器健康、`18432` 博客、`18055` Directus、PostgreSQL/Redis 无发布端口、发布即更新、素材页复制数据和二维码、备份恢复、自动部署回滚。节点小宝映射完成后再从真实公网 HTTPS 和微信内置浏览器测试首页、文章、图片、互动、证书、安全区域、无局域网/Token 泄漏及容器重启恢复。

# 节点小宝公网映射

## 目标

第一阶段不购买、不申请、不绑定独立域名。节点小宝提供唯一公网 HTTPS 地址，作为微信公众号菜单、阅读原文和微信群分享入口。

```text
节点小宝真实 HTTPS 地址
  -> 127.0.0.1:18432
  -> Caddy
  -> Astro H5 博客
```

Directus 后台只允许飞牛局域网访问：`http://192.168.5.104:18055`。不得为后台、PostgreSQL、Redis、SSH、Docker API 或飞牛管理后台创建公网映射。

## 变更规则

- 变更前备份节点小宝现有配置并记录规则清单。
- 不删除、不覆盖、不重命名任何原规则。
- 只新增一条 HTTPS 前台映射，目标为 `127.0.0.1:18432`。
- 若节点小宝不接受 loopback，才改用飞牛实际局域网地址的 `18432`。
- 真实 HTTPS 地址只能从节点小宝界面读取，不在代码中写死或伪造。

获得地址后只修改 NAS `PUBLIC_BASE_URL` 并重建 web；`PUBLIC_ADMIN_URL` 和 `DIRECTUS_PUBLIC_URL` 继续使用 `http://192.168.5.104:18055`。

## 微信验收

在非局域网网络和微信内置浏览器检查：首页、`/posts/china-street-dance-decade-review`、公众号素材页、图片、专家切换、复制链接、二维码、返回顶部、安全区域和 HTTPS 证书。公开 HTML 不得出现局域网地址、Directus Token 或数据库地址。

公众号菜单只需设置一次并指向博客首页。博客发布后首页自动更新，但公众号不会自动产生动态或自动群发；用户从素材页复制内容并在公众号后台人工审核发表。

## 恢复

若本次新增规则异常，只删除本次规则并恢复备份；不得触碰原有映射。Caddy/web 或飞牛重启后都要重新验证同一公网 HTTPS 地址可以恢复访问。

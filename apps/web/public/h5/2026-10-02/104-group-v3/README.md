# 104 GROUP 宣传站 v3（2026-10 重构）

纯静态网站，没有任何第三方依赖或外部 CDN。整个文件夹传到服务器即可，用域名生成二维码。

## 上线
1. 把 `site-v3` 文件夹里的全部内容上传到服务器网站根目录（或子目录）。
2. 浏览器打开 `https://你的域名/` 确认能访问，再用这个网址生成二维码。
3. 必须用 http(s) 访问；直接双击 index.html 时 3D 贴图会被浏览器拦截。

## 要改的信息：只改 `js/config.js`
- 微信二维码：把图片放到 `assets/img/wechat-qr.png`，然后填 `wechatQR: 'assets/img/wechat-qr.png'`
- 创立年份、里程碑、工厂面积、日产能、人数、纱支、微信号、电话
- 留空的项目会自动隐藏，不会显示占位符

## 音乐
`assets/audio/104-jazzhop.mp3`：程序合成的 jazz hiphop 循环（约 44 秒，88 BPM，Rhodes 电钢 + 低音贝斯 + boom bap 鼓 + 黑胶底噪），无版权问题。
- 微信内打开：进页自动播放（WeixinJSBridge）。
- 普通手机浏览器：浏览器禁止有声自动播放，客户第一次触摸屏幕时开始播放，右上角可开关。
- 想换成正版曲：同名替换这个 mp3 即可。

## 技术
- `js/gl.js`：自写的轻量 WebGL 引擎（不依赖 three.js），只渲染屏幕上能看到的 3D 场景，像素比上限 1.75。
- 不支持 WebGL 的手机会自动换成实拍图片。
- 图片已压缩为 WebP，整站约 5MB。
